# Jam Night

新店花園新城的社群音樂即興活動 Jam Night 的介紹網站。
A one-page site introducing Jam Night, a community music jam on a hillside in Xindian, New Taipei.

- 純靜態 HTML，直接用瀏覽器打開 `index.html` 即可預覽。
- 照片為 WebP 格式，每張有 800px 與 1600px 兩種尺寸。
- Instagram：[一塊樂土 @a_happy_together_land](https://www.instagram.com/a_happy_together_land/)
